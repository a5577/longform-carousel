# 写作与查证

这个模板的正文页是**纯长文**：一屏 22 字 × 23 行，扣掉段间距和每段最后那半行，**一页实际排 400-450 字**，6 页上下就是 2500-2800 字。读者翻的是图，所以句子要能一眼扫过去，段落要短。

## 一、定题

先写 2-3 个候选角度，按下表打分再定，不要拿到的第一个想法就开写：

| 判据 | 要什么 |
| --- | --- |
| 一手材料 | 官网、政策原文、年报、招录公告、论文、可核实的当事人经验，至少够支撑 10 处具体内容 |
| 收藏动机 | 读者会因为「以后要用」而收藏，而不是看完点个赞就走 |
| 反常识或有立场 | 标题里能说出一个明确判断，而不是「关于 X 的几点思考」 |
| 不靠背诵 | 内容能被理解、被复用，而不是又一份背了就忘的模板 |

主题**不限于工作**，判据对哪个领域都一样。能出好内容的方向大致有这些：

| 领域 | 常见题目 |
| --- | --- |
| 职场 | 面试、简历、跳槽、转行、考公考编、实习、和领导沟通 |
| 读研 / 学业 | 选导师、读研日常、开题、写论文、投稿被拒、考研保研、期末 |
| 生活 | 租房、搬家、装修、收纳、省钱、做饭、买菜、体检、看病 |
| 旅行 | 路线、签证、机票、淡季出行、青旅、徒步、周边游 |
| 身体 | 健身、减脂、跑步、睡眠、久坐、伤后恢复 |
| 兴趣与技能 | 摄影、剪辑、学英语、考驾照、乐器、手工 |
| 关系与家庭 | 和父母沟通、异地、带娃、宠物、独居 |

不管选哪个领域，都别写成「X 的十个技巧」：要有**一个人、一段时间、一件具体的事**。同一个话题，写「我第三次搬家才搞明白的事」永远比写「搬家注意事项」有人看。

## 二、查证

给每一条要上版面的说法建一行记录，写在笔记目录的 `来源.md` 里：

```
## 事实
- 说法：<一句话，能直接上版面>
  出处：<标题> — <URL>
  时间：<发布或更新日期>　访问：<日期>
  原文：<逐字摘录关键句，不超过 40 字>

## 不写的
- <流传很广但找不到出处的说法>：<为什么放弃>
```

规则：

- **一手优先**。二手转述只能用来找线索，最终引用回到原文。
- 单个案例不能写成「大家都这样」。写清主体、时间、范围。
- 数字必须有主语和口径（谁、哪一年、怎么算的）。查不到就不写，不要用「大约」「据不完全统计」糊过去。
- 政策类内容写发布机构、文件号和有效期。
- 观点和事实分开：自己的判断用「我建议」「我的经验是」起头，别伪装成结论。

## 三、写正文

结构（对应原帖的节奏）：

1. **开场 2 段**：从一个具体、能让人对号入座的处境切入；第二段交代这篇的边界——哪些是实战验证过的，哪些不碰。
2. **主体 2-4 个编号部分**：`第一，…… 第二，…… 第三，……` 直接写在段首，不用小标题，不用项目符号。
3. **收尾 2 段**：先说这段内容覆盖不到什么，降低读者预期；再给一句鼓励收住。

写法：

- 每段 3-8 行（约 60-180 字）。一整页 23 行最多装 3-4 段，段落太长会显得满屏都是字。
- 第一人称，说自己做过什么、栽过什么跟头，比「大家应该」有用。
- 每个编号部分里给一个**具体动作**：花两分钟列三点、每天录音两分钟只改一个问题、确定单位后看近两年重点项目。没有动作的部分就是空话，删掉。
- 讲压力题、加班、外派这类内容时给「稳的答法」，但保留态度，不做成一味讨好的话术。
- 不写「万能」「包过」「上岸秘籍」。原帖的价值恰好在它反对背诵模板。
- 数字用阿拉伯数字，中文和数字之间不加空格。
- 段落长度交错，每段开头别用同一个模子。写完先按下一节自查一遍 AI 腔。

## 四、去掉 AI 腔

判据只有一条：**换一个真人来写，会不会这么写**。AI 腔不是「用词高级」，是**没有具体的人、时间、地点、数字和代价**。按下面四条改：

1. **抽象换成能看见的东西**。不写「提升了效率」，写「以前要 40 分钟的活现在 12 分钟」；不写「信息太杂」，写「收藏了 30 篇笔记，一篇没再打开过」。
2. **长短句交错**。每段至少有一句在 12 字以内。整段都是 30-40 字的句子，读起来就是机器在匀速输出。
3. **允许不确定和失败**。真人会写「我也没搞明白为什么」「第二周就放弃了」。通篇正确、通篇都有结论，是 AI 最明显的特征。
4. **每段开头别用同一个模子**。「第一…第二…第三…」只在正文主体用一次，其余段落用一件具体的事开头。

下面这些词和句式，**写作时就不要用**（`check.py` 会扫出来提醒）：

| 类型 | 不要写 |
| --- | --- |
| 空洞收尾 | 综上所述、总而言之、总的来说、由此可见、以上就是、希望对你有帮助 |
| 万能开场 | 在当今社会、在这个快节奏的时代、随着社会的发展、随着科技的进步 |
| 排比套话 | 不仅是…更是…、让我们…、无论你是…还是…、既能…又能… |
| 互联网黑话 | 赋能、助力、打造、抓手、闭环、颗粒度、底层逻辑 |
| 平台腔 | 干货满满、保姆级、一文读懂、必看、深度好文、纯干货 |
| 空形容词 | 极大地、显著地、深深地、充分地、很大程度上 |
| 定义句开场 | 「XX 是一种……」「所谓 XX，就是……」 |

对照一下：

> ✗ 在当今快节奏的社会中，面试已成为每个求职者必须面对的重要挑战，如何高效准备值得深入思考。
> ✓ 我第一次面试被问「你为什么来我们单位」，我说「因为稳定」，面试官当场就低头写字了。

段落长度也要交错：一页 23 行全是等长的段，翻起来就像模板。每段字数过于接近时 `check.py` 会提醒。

## 五、写封面

- **标题行**：3-4 行，每行 4-8 字，末行短（2-4 字）最有力；整句要能一口气读完，且带明确判断。手写断行，念一遍看会不会断错气。
- **导语**：2 行以内，60 字以内，给一个「三大关键」式的承诺，把读者送到正文页去。
- **插画**：图要解题——把标题遮住、只看图能猜到讲什么才算合。主体从这篇的具体人和物里来，提示词写法见 [SKILL.md](../SKILL.md) 的「封面插画」一节。
- 不要在封面写「收藏」「转发」「点赞」。

## 六、写发布件

图上给的是正文页；点开之前读者先看到的是**题目**和**文案**。这两样要单独写，不能拿封面标题凑。

| 交付件 | 写什么 | 长度 |
| --- | --- | --- |
| 标题候选 | 2-3 个能直接发的题目。要有一个明确判断或具体收益，不用「XX 指南」「纯干货」 | 每条 ≤20 字 |
| 帖子文案 | **3 段**（发布时中间空行）：第 1 段抛一个具体场景或结论；第 2 段给本文最有用的一两点，最好点出正文页里的关键动作；第 3 段收一句 + 一句引导 | 每段 40-120 字，总 150-300 字 |
| 话题标签 | 3-6 个，一大两小：1 个大词（#求职 #考研 #旅行）+ 2-3 个细分词 | — |
| 首评 | 出处与补充：把 `来源.md` 里的关键出处、延伸资料放这里（图上不写出处） | ≤200 字 |

- 三段不要写成「背景—要点—总结」。第 1 段要勾人（一个具体的坑、一个数字、一个反常识的判断），第 2 段要有用（看完这段就有收获），第 3 段要松（一句人话收尾，再给一句不讨好的引导，比如「完整版在图上第 3 页」）。
- 帖子文案里不写「收藏」「点赞」「关注」「干货」「必看」。
- 帖子标题不要和封面标题一模一样，重复会显得敷衍。
- 一个具体场景永远比一句总结有效：「上周三在机场被告知航班取消」比「旅行中总会遇到突发状况」强。

## 七、字数与时长

正文默认 **2000-3500 字**。用户明确说了要多少就按他说的写，但**上限是 5000 字**——`check.py` 超过 5000 字直接报错，压不下去就删重复的例子和空话（能删的都是空话，不能删的一定是具体的事）。

一页 22 字 × 23 行，扣掉段间距和每段末尾的半行，实测大约 **400 字/页**（段落多、短句多会更少）：

| 目标字数 | 正文页数（约） |
| --- | --- |
| 2000 | 5 |
| 2500 | 6 |
| 3000 | 8 |
| 3500 | 9 |
| 4000 | 10 |
| 4500 | 11 |
| 5000 | 13 |

约 3500 字（9 页）往上，小红书正文容易被折叠或截断，`check.py` 会提醒。用户坚持要写长那就写，但要先把这件事告诉他。

封面字数行由渲染器按正文非空白字符数自动生成，阅读时长按 480 字/分钟取整（2800 字 → 6 分钟）。不要手改这个数字，`check.py` 会核对。`笔记.json` 里的 `字数目标` 是可选的，写了 `check.py` 会核对实际字数和它差得远不远。
